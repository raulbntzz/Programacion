------ Introducción
En este proyecto, se nos ha pedido
que realicemos una aplicación
para una tienda de productos otaku
donde debemos aportar opciones para
realizar las opciones básicas de
CRUD. Además se pide también que
hagamos llamadas a una API a través
de open router para que así, el
usuario, tras introducir el tipo
de producto y la franquicia, sugiera
un nombre del producto indicado y te
pregunte a cerca de si quiere introducir
el producto en la base de datos con
ese nombre.
